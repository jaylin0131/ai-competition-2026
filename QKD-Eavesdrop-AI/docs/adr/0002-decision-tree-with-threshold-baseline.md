# 主模型用決策樹，一定要和 QBER 門檻法比較

> 2026/10/11 補充（[ADR-0004](0004-pivot-to-link-health-diagnosis.md)）：對照模型改為梯度提升；基準除了固定門檻，再加「指數平滑基準線」與「物理規則表」；比較一律在相同誤報率（10%、5%、2%）下進行，並以攻擊類型分段。

BB84 的傳統做法是 QBER 超過約 11% 就判定不安全，所以評審第一個問題一定是「為什麼不用門檻就好？」。我們用決策樹當主模型，因為它能畫出來、讓評審看懂判斷依據；同時以隨機森林作為效能對照。所有成果數字都必須和「固定門檻」與「最佳門檻」兩條基準線並列，並依攔截比例分段呈現偵測率。如果 AI 在某個情境沒有贏過門檻法，也照實寫出來，並說明原因。
