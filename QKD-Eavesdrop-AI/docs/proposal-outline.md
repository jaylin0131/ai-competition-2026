## 決賽可能被問的問題

| 問題 | 回答方向 |
|---|---|
| 為什麼不用 QBER 門檻就好？ | PNS、致盲在 QBER 上完全看不到；拿出同誤報率比較表 |
| AI 讓量子通訊更安全嗎？ | 不是。金鑰安全仍由協定中止門檻保證；AI 負責提早預警、分辨原因、減少誤中止 |
| 寫幾條規則不就好？ | 單一特徵（PNS）規則確實不錯，我們也照實比較；但多種狀況並存時 ML 明顯較好，所以規則＋ML 並用 |
| 資料是模擬的，真實世界能用嗎？ | 承認限制；參數取自文獻；模型只用真實設備也量得到的統計量 |
| 會不會 overfit？ | 交叉驗證、深度曲線、未見過測試集 |
| 有沒有標籤洩漏？ | `common/schema.py` 明列禁用欄位並在訓練前檢查 |
| 為什麼竊聽一定會留下痕跡？ | 量子不可複製定理；Eve 猜錯基底時會擾動光子狀態 |
| 誤判的代價？ | 把攻擊判成良性劣化最危險，所以加重攻擊類權重；誤中止會浪費金鑰，所以固定誤報率比較 |
| 為什麼選決策樹？ | 可解釋、評審看得懂；梯度提升對照顯示差距多少，SHAP 說明每個判斷的依據 |
| 每個人負責什麼？ | 每人 30 秒：負責的部分、最難的問題、怎麼解決 |
