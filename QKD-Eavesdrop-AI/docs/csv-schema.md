# CSV 欄位規格（A 組 → B 組介面）

> 狀態：**草案 v2**（2026-10-11 依參賽進度分析報告改版），目標 10/14 定稿（決策 D5）。定稿後要改欄位，必須 A、B、C 三組同意，並同步修改 [`common/schema.py`](../common/schema.py)。
> 程式一律從 `common/schema.py` 讀欄位名稱，不要在程式裡手打字串。
> v1（三類 normal／noise／eve、逐批次只看 QBER）已廢止，原因見報告 4.2.1：決策樹只會重新發現 QBER 門檻；逐光子標記的上限只有 AUC 0.61。

一列＝一個「回合」（例如 10^5–10^6 個脈衝跑完一次誘騙態 BB84 後的統計）。**不可逐光子標記。**

## 欄位

| 欄位 | 型別 | 單位／範圍 | 說明 | 可當特徵 | 階段 |
|---|---|---|---|---|---|
| `round_id` | int | | 回合編號 | ✗ | 一 |
| `timestamp` | float | 小時 | 模擬時間點，用來模擬老化與漂移的緩慢變化 | ✗ | 一 |
| `seed` | int | | 亂數種子，用來重現與切分未見過測試集 | ✗ | 一 |
| `n_pulses` | int | 脈衝數 | Alice 每回合發送的脈衝數 | ✗（固定值） | 一 |
| `gain_signal` | float | 0–1 | 訊號態偵測率 | ✓ | 一 |
| `sift_ratio` | float | 0–1 | 基底相同的比例，理論約 0.5 | ✓ | 一 |
| `qber` | float | 0–1 | 訊號態總錯誤率 | ✓ | 一 |
| `qber_z` | float | 0–1 | Z 基底錯誤率 | ✓ | 一 |
| `qber_x` | float | 0–1 | X 基底錯誤率 | ✓ | 一 |
| `err_var_window` | float | | 滑動視窗錯誤率的變異數 | ✓ | 一 |
| `gain_decoy` | float | 0–1 | 誘騙態（ν≈0.1）偵測率 | ✓ | 二 |
| `gain_vacuum` | float | 0–1 | 真空態偵測率（暗計數＋雜散光） | ✓ | 二 |
| `decoy_signal_ratio` | float | | `gain_decoy / gain_signal`，PNS 時由約 0.20 掉到約 0.13 | ✓ | 二 |
| `qber_decoy` | float | 0–1 | 誘騙態錯誤率 | ✓ | 二 |
| `distance_km` | float | 5–80 | 光纖距離 | ✗（D6，只顯示） | 一 |
| `loss_db` | float | dB | 通道總損耗 | ✗（D6，只顯示） | 一 |
| `label` | str | 見下表 | **目標 y** | — | 一 |
| `attack_ratio` | float | 0–1 | 攻擊作用的光子或時間比例 | ✗ **禁止** | 一 |
| `fault_severity` | float | 0–1 | 良性故障強度 | ✗ **禁止** | 一 |
| `faults` | str | 以 `;` 分隔 | 同時存在的良性故障清單 | ✗ **禁止** | 一 |
| `noise_level` | float | 0–1 | 背景雜訊設定值 | ✗ **禁止** | 一 |

衍生特徵（在 `ml/features.py` 計算，不寫進 CSV）：`qber_basis_gap = |qber_z − qber_x|`（E4：總 QBER 相同時分辨偏振漂移與截取重送的關鍵）。

## 標籤定義（七類，決策 D7、D9）

| label | 類別 | 物理特徵 | QBER | 階段 |
|---|---|---|---|---|
| `normal` | 正常 | 各計數率穩定 | 低 | 一 |
| `fiber_aging` | 良性 | 所有計數率一起下降，誘騙比不變 | 幾乎不變 | 一 |
| `pol_drift` | 良性 | 只有單一基底錯誤率升高 | 單一基底升高 | 一 |
| `intercept_resend` | 攻擊 | 兩基底錯誤率同步升高 | 升高 | 一 |
| `stray_light` | 良性 | 真空計數暴增 | 微升 | 二 |
| `pns` | 攻擊 | 誘騙／訊號計數比下降 | 完全不變 | 二 |
| `blinding` | 攻擊 | 暗計數歸零，QBER 低於物理下限 | 反而降低 | 二 |

故障並存時的標籤規則：有任何攻擊 → 標攻擊類別；否則標最嚴重的良性故障；都沒有 → `normal`。

## 真實化要求（避免「100% 準確率」）

1. 有限統計：每回合脈衝數要少到讓統計量有抖動（報告的真實版比理想版少 10 倍）
2. 故障並存：良性故障隨機同時出現，寫在 `faults` 欄（禁止當特徵）
3. 弱攻擊：攻擊只作用於部分時間或部分光子（`attack_ratio`）

## 檔案

- 訓練用：`data/raw/dataset_v{N}.csv`
- 未見過測試集：`data/raw/holdout_v{N}.csv`（不同亂數種子，B 組只在最後評估時使用）
- 留一攻擊驗證：B 組訓練時拿掉一種攻擊，測試能否當成「異常」抓到
- 編碼 UTF-8、逗號分隔、第一列為欄位名稱、小數用點
