# 詞彙表

| 詞彙 | 說明 |
|---|---|
| QKD | 量子金鑰分發（Quantum Key Distribution），用量子態傳送加密金鑰 |
| BB84 | 最經典的 QKD 協定（1984），用兩組基底的偏振光子傳位元 |
| Alice／Bob／Eve | 發送端／接收端／竊聽者 |
| 基底（Z、X） | 量測光子的兩種方向（直線／對角）。量錯基底，結果就是隨機的 |
| Sifting（基底比對） | Alice 與 Bob 公開比對基底，只保留基底相同的位元，約剩一半 |
| QBER | 量子位元錯誤率（Quantum Bit Error Rate），抽樣比對 Alice 與 Bob 的位元算出 |
| 攔截重送（intercept-resend） | Eve 量測光子再重送；全攔截時 QBER 約 25% |
| 部分攔截 | Eve 只攔截一部分光子，QBER 增加較少，容易和雜訊混淆。本專案主要情境 |
| PNS 攻擊 | 光子數分離攻擊：從多光子脈衝分走一個光子，QBER 完全不變，但誘騙／訊號計數比下降 |
| 誘騙態（decoy state） | Alice 隨機混用訊號（μ≈0.5）、誘騙（ν≈0.1）、真空三種強度，比較各強度的偵測率就能發現 PNS |
| 偵測器致盲（blinding） | 用強光讓偵測器變成古典模式，Eve 控制 Bob 的結果；暗計數歸零、QBER 反而降低 |
| 光纖老化／偏振漂移／雜散光 | 三種良性劣化：計數率一起下降／單一基底錯誤率升高／真空計數暴增 |
| 回合（round） | 一次跑完大量脈衝後的統計，是本專案資料與標籤的最小單位（不可逐光子標記） |
| 同誤報率比較 | 先把每種方法調到相同誤報率（例如 10%），再比偵測率，才公平 |
| 留一攻擊驗證 | 訓練時拿掉一種攻擊，測試模型能否把它當成異常抓到 |
| 暗計數 | 偵測器在沒有光子時誤觸發 |
| 門檻法 | 傳統做法：QBER 超過固定值（約 11%）就判定不安全。本專案的基準線 |
| 標籤洩漏 | 把含有答案資訊的欄位（如 `attack_ratio`、`faults`）當成特徵，成績會虛高 |
| 未見過測試集（holdout） | 用不同亂數種子產生、訓練與調參時完全不碰的測試資料 |
| 召回率 | 真正的竊聽中被抓到的比例。本專案最重視竊聽類的召回率 |
