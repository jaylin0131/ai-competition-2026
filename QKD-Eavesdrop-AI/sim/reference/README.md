# 參考程式（指導老師提供）

請把老師在參賽進度分析報告附錄 A 提到的三支程式放在這裡（原位於老師桌面「2026 全國AI 專題創意競賽」資料夾，目前尚未取得）：

| 檔案 | 內容 |
|---|---|
| `bb84_feasibility.py` | E1–E4：原設定、逐光子標記、飄移＋部分攔截、基底不對稱（約 2.5 分鐘） |
| `decoy_diagnosis.py` | 誘騙態七類理想統計；QBER 門檻 vs 決策樹；良性訓練的異常偵測 |
| `decoy_hard.py` | 真實條件（有限統計、故障並存、弱攻擊）；門檻、規則表、決策樹、梯度提升同誤報率比較 |

規則：這些程式只能當參考。A、B 組必須自行理解後重寫成自己的版本（`sim/`、`ml/`），並在說明書參考文獻中註明來源。`sim/` 與 `ml/` 的程式不要 import 本資料夾。
