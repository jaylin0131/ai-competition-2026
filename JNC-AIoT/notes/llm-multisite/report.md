# S11 跨場域本機工單改寫實測（2026-11-15）

五個已下載的模型各跑同一批 13 張工單。河川 3 張，羊舍、育成北側、育成一廠、東北角及工地微氣候各 2 張。
觀測依據見 [場域事件總表](../eda/events.md)。設備名稱、處置、期限、優先級及備援由測試情境擬定，待隊員或企業確認後才可用於現場。
輸入為固定工單。測試範圍是本機文字改寫，資料來源沒有維修工單紀錄。

使用原 S11 提示詞、生成參數、180 秒逾時及暖機排除方式。環境與魚塭測試相同，使用 RTX 3050 Laptop GPU 4 GiB、Ollama 0.40.15。
以數字檢查放行且逐張複核無實質偏差為通過。複核涵蓋設備、觀測與數值、處置、期限、優先級及備援。數字檢查擋下的工單直接判定未通過。
通過也包含接近逐字保留的輸出。此指標衡量原意保留，白話改寫幅度另看案例。

## 重跑方式

啟動本機 Ollama 後，從 JNC-AIoT 執行以下命令。每次指定新輸出目錄。原工單見 [orders.json](orders.json)。

```powershell
.\.venv\Scripts\python.exe scripts\llm_test.py --orders notes/llm-multisite/orders.json --output-dir notes/llm-multisite-rerun granite4:micro granite4:tiny-h gemma3:4b ministral-3:3b gemma4:e4b
```
